# CIS 022 – Programming Using C++

Programming Using C++ · Solano Community College · Fall 2026 · Instructor: Ben Allen

**[Read the syllabus](syllabus.md)** for grading, policies, the recommended textbook, and office hours.

Class meets in person on Tuesdays and Thursdays in Room 503. Class is listed at 11:00 AM, but lecture starts at **11:10 AM** ("Berkeley time"); the ten minutes before are for informal questions. Tuesdays tend to be mostly lecture, and Thursdays mostly lab time for larger assignments. [Details](syllabus.md#crucial-details)

This is **not** a first programming class: some prior experience with C++, Java, Python, or a similar language is assumed. If you're new to programming, CIS 001 is the place to start.

## Using this site

- Course materials are all available on the class [GitHub repository](https://github.com/ben-allen/CIS-022/). As I develop new materials I post them on GitHub and then later mirror them on Canvas -- as such, there will generally be "early-access" materials for future weeks on the GitHub.
- Assignments are turned in on Canvas.
- You don't need a GitHub account to view the material on the GitHub repo. Slides are PDFs and open right in your browser.
